# ComicHero

ComicHero is a responsive Hugo theme with a comic-book look, suitable for blogs, documentation, and creative portfolios.

## Core features

- Responsive layout across desktop, tablet, and mobile
- Light/dark mode toggle with persisted preference
- Comic-style UI elements, typography, and motion effects
- Home hero and section-based content presentation
- Rich shortcode set for expressive content blocks

## Install

1. Copy this folder into your Hugo project's `themes/` directory.
2. Set the theme in your Hugo config:

```toml
theme = "comichero"
```

## Run demo

From repository root:

```bash
hugo server --source exampleSite --themesDir themes
```
